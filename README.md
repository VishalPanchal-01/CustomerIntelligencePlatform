# AI-Powered Customer Intelligence Dashboard

The Streamlit dashboard provides a unified business view of the
Customer Intelligence Platform.

## Dashboard Modules

The application includes:

- Executive Overview
- 360° Customer Explorer
- Churn Intelligence
- Customer Segmentation Intelligence
- Customer Lifetime Value Intelligence
- Recommendation Intelligence

## Customer Identifier

The dashboard uses:

Customer ID

as the canonical customer identifier.

Older pipeline artifacts containing `CustomerID` are normalized
before dashboard usage.

## Input Dataset

The dashboard reads:

artifacts/dashboard/unified_customer_intelligence.csv

The file is generated by the customer intelligence batch pipeline.
